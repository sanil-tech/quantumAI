## 2. Strict Dataset Source Isolation Policy
To guarantee 100% statistical honesty and prevent synthetic contamination:

1. **Source Demarcation:** Every record in `realMarketShadowObservationService` carries an explicit `observationSource`:
   - `REAL_MARKET_SHADOW`: Originates strictly from live real-market tick processing. Only this category is included in production longitudinal metrics.
   - `CALIBRATION`: Generated by test/audit scripts to verify mathematical aggregations. Strictly excluded from production evidence metrics.
   - `BACKTEST` / `TEST_FIXTURE` / `SYNTHETIC`: Quarantined from real performance accounting.
2. **Zero-State Handling:** When 0 real-market observations have been recorded, the engine outputs `realObservationCount = 0`, `tradeCount = 0`, `netPnl = 0.00`, and `sampleStatus = NO_REAL_OBSERVATIONS` / `PRELIMINARY` without synthesizing performance.
